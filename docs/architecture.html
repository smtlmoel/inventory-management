Factory Inventory Management System

A demo full-stack app: a Vue 3 single-page dashboard talking to a FastAPI service that serves in-memory data loaded from JSON files. There is no database.

System architecture

Tech stack

Frontend

  • Vue 3 (Composition API), Vue Router 4
  • Vite 8, @vitejs/plugin-vue
  • Axios for HTTP
  • Custom SVG charts, CSS Grid layouts
  • Custom i18n (en, ja)

Backend

  • Python ≥ 3.11, FastAPI, Uvicorn
  • Pydantic v2 models
  • Managed with uv
  • Plain Python list filtering, no ORM

Data

  • JSON files in server/data/
  • Loaded by mock_data.py
  • Generated by generate_data.py
  • Mutations are not persisted

Testing and tooling

  • pytest + FastAPI TestClient (tests/backend)
  • No frontend tests
  • Claude Code agents, skills and hooks in .claude/
  • GitHub and Playwright MCP servers

Data flow

  1. The user changes a filter (period, warehouse, category, order status) in FilterBar.
  2. useFilters holds the state as module-level refs, so every view shares one singleton. getCurrentFilters() maps it to warehouse, category, status and month.
  3. The active view calls a method in api.js, which appends the non-"all" values as query parameters and sends an Axios request.
  4. FastAPI routes the request, runs apply_filters and filter_by_month (quarters like Q3-2025 expand through QUARTER_MAP) over the in-memory lists.
  5. The response is validated against a Pydantic model and returned as JSON.
  6. The view stores the raw result in refs (allOrders, inventoryItems) and derives chart and KPI values with computed properties.

Observations

Client and server are out of sync. api.js calls /api/tasks (GET, POST, PATCH, DELETE) and /api/purchase-orders (POST, GET), but server/main.py defines none of them. The PurchaseOrder models exist, so those routes were likely removed or never added. Calls from the tasks modal and purchase-order flow will return 404.
Hardcoded API URL and open CORS. The base URL is a constant in api.js, and the server allows all origins with credentials. Fine for a local demo, not for deployment.
Unrouted view. views/Backlog.vue exists but is not registered in the router.
